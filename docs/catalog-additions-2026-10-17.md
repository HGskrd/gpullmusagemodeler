Jais ASR plots its published Arabic macro-average WER of 22.85% over six IFM evaluation sets, with the protocol labeled separately; it has no English/French WER point.

Bonsai native storage includes the PTQ1_0 language file **and** recommended Q8 vision projector; its canonical precision key is `bf16` only to select conservative matrix compute. Bolt IQ2 uses the same conservative compute mapping. Neither claims FP4 tensor-core performance. Their packed containers, scales and retained tensors are included in published file/index byte totals. Optional draft artifacts are not enabled.

Muse core geometry and bytes use the public official card and Hub dtype metadata because gated config/index access returned 401. Its KV cache conservatively charges all layers as global attention; the actual local/global split needs checkpoint access before it can be claimed exact.

MiMo Flash global/local KV heads are 4/8 respectively, with 192d QK and 128d values. Mixed native MXFP4 includes modality and draft tensors. Encoder execution and speculative acceleration are uncalibrated.

EmbeddingGemma uses pinned config geometry (512-token local window; 512d global heads), which conflicts with the prose card. Its served sequence limit is 8192. Perplexity v2 uses a 1024 query / 4096 document serving profile, includes full FP32 checkpoint residency, and estimates text-input throughput only.
