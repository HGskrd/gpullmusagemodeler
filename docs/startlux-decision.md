# StartLux-Decision catalog — 11 November 2026

The Decision picker includes all eight v1.1 checkpoints (five Instant and three AutoThink), plus all six original v1 checkpoints, including 35B-A3B. These are local planner catalog entries; no weights are downloaded and no inference server is connected.

Each release is pinned below. Architecture comes from its `config.json`; parameter counts and native residency come from the physical safetensors headers, including vision and any stored MTP tensors. The small Instant/v1 checkpoints retain their FP32 linear-attention tensors. AutoThink shard-index `total_size` values disagree with their physical payloads: 4B says 9,078,619,848 bytes but contains 9,078,531,072; 9B says 18,819,721,088 but contains 18,819,627,488; 27B says 54,713,606,264 but contains 54,713,457,120. Physical tensor payloads determine the catalog values. Only metadata and byte-range tensor headers were fetched, never weights.

Instant uses bidirectional full-attention layers and causal linear layers; the other variants are causal. Every fourth backbone layer is full attention. All requests include the complete formatted state, question and option tokens; each question incurs another full forward pass. The single-read estimate accepts up to 26 listed options; larger lists require unmodeled group rounds. No prefix-cache savings are credited, including on causal variants.

Native positional capacity is 262,144 tokens. The [official engine deployment notes](https://github.com/StartLuxLabs/StartLux-Decision/blob/a99977d9332decc9fb27a2488b4a83b533b6cd5f/docs/deployment.md) cap Instant at 131,072 because its whole prompt must be processed together. The catalog uses that operational cap, and 262,144 for v1/AutoThink with vLLM 0.31; older engine versions can have lower limits. Instant requires the StartLux noncausal plugin or equivalent engine support, with prefix caching and chunked prefill disabled.

AutoThink entries explicitly say **think_mode=never** in their picker names and model notes. Their estimates cover the initial causal readout only. Conditional reasoning with auto/always, gate frequency, thought length, second readouts and MTP acceleration are unmodeled. These estimates must not be interpreted as default AutoThink end-to-end throughput. The [official AutoThink card](https://huggingface.co/startlux-models/StartLux-Decision-v1.1-4B-AutoThink/blob/23dd4c513ef387705bb13fd8caadc2d5c863082f/README.md) documents the never mode.

The 35B-A3B entry uses the released rounded 3B active-parameter proxy and 256 experts with eight selected per token. Exact checkpoint residency includes its stored MTP layer; no speculative speedup is credited. Dense text compute conservatively uses all stored parameters, including modality/MTP tensors. Vision encoding, custom runtime overhead and calibrated decision quality remain unmodeled. The existing decision roofline is unchanged: results are closed-form capacity estimates requiring deployment calibration, with zero generated tokens and no generation revenue.

Native BF16/mixed FP32 storage is exact; other planner precision choices are hypothetical conversions, not claims about validated quantized runtimes or quantization quality. Published GGUF/MLX alternatives are not separately inventoried in this addition. The weights use CC BY-NC 4.0; commercial use requires a separate StartLux license. The inference code uses Apache-2.0. See each pinned model card.
